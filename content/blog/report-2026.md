2026年8月1日、横浜にて JP_Stripes Connect 2026 を無事に開催することができました。ご来場いただいた皆様、登壇者の皆様、スポンサーの皆様、そして会場をお貸しいただいた岩崎学園情報科学専門学校さまに、実行委員会一同あらためて御礼申し上げます。当日の運営でご不便をおかけした点もあったかと思いますが、多くの方のご協力で最後まで走りきることができました。

この記事は、終了後アンケートの生データをもとにした開催報告です。良かった点も課題も含めてお伝えします。

## 開催実績

- 事前登録 118名 / 当日参加 65名（うち懇親会43名）
- 15セッション・16名の登壇者・2トラック構成
- 終了後アンケート回答 30名

前回（2025年）は事前登録99名・実参加53名でしたので、規模としては一回り大きくなりました。

## セッションの評価

終了後アンケートで、各セッションについて「今すぐ試す・提案したい」「参考になった」「あまり参考にならなかった」「参加していない」の4択でお伺いしました。**全セッションが好意的評価（今すぐ試す＋参考になった）86%以上**という結果でした。

キーノート、Stripe x Cloudflare の x402/MPP 対談、AI × Stripe セッション、そして Stripe Terminal 関連の2セッションは、「今すぐ試す・提案したい」と答えた方の比率が特に高く、実装イメージを持ち帰った方が多かったセッションでした。

> 値付けは「いくらにするか」ではなく、「誰を倒しに行くか」

> 価格は「いくら？」ではなく「誰？」が重要。市場にいる人を定めて「驚き」を得られる価格を戦略から導く。

綺麗な成功事例だけでなく、迷いや割り切りの判断まで話してくださる登壇者の方が多かったことが、この反応につながっていると考えています。

当日の会場やセッション、懇親会の様子は[イベント写真ギャラリー](/photos/)でもご覧いただけます。

## 登壇者の発信が、最大の集客経路でした

これは共有しておきたいデータです。参加者に「このイベントをどこで知りましたか」と伺った結果です（回答30名）。

| きっかけ | 割合 |
|---|---:|
| 登壇者の告知や紹介 | 33% |
| JP_Stripes の Connpass | 27% |
| Stripe からのメール・SNS | 17% |
| 個人紹介・検索など | 13% |
| Cloudflare / 和田さんの投稿 | 10% |

登壇者ご自身の告知が、公式Connpassを上回って最多でした。

運営としては公式チャネルの告知文を磨くことに時間を使っていたのですが、実際に人を動かしていたのは「この人が話すなら行く」という力でした。登壇者の皆様が事前に投稿してくださった1本1本が、そのまま参加者につながっています。

## 資料公開のお願い（登壇者の皆様へ）

登壇資料を Speaker Deck / Docswell 等で公開いただける場合、URLを実行委員会までお知らせください。公式サイトのセッションページからリンクさせていただきます。

すでに公開いただいている方もいらっしゃり、ありがとうございます。公開済みの資料は[プレゼンテーション一覧ページ](/presentations/)からご覧いただけます。

## 参加者からいただいた「次に聞きたいこと」

アンケートの自由記述で挙がったテーマを共有します。次回開催は現時点で未定ですが、今後のセッション企画の材料になれば幸いです。

- ハンズオン・ワークショップ形式（7件）
- AI・エージェンティックコマース関連（4件）
- 価格設計・プライシングをテーマにした回（2件）
- 越境ビジネス、BtoC特化、Stripe機能の深掘り、自動テスト、Connect など

また、今回の参加者のうち複数名から「次は登壇したい」「地元で立ち上げたい」というお声をいただきました。登壇者の話を聞いて、話す側に回ろうと考えた方がいらっしゃったということです。

JP_Stripes は、聞く側だった人が話す側に回ることで続いてきたコミュニティです。今回それが起きたのは、登壇者の皆様が「自分もこれくらいなら話せるかも」と思わせる話し方をしてくださったからだと思っています。

## 最後に

決済・サブスクリプション・値づけの判断は、本番に投入してからやり直すことができません。だからこそ、他の人がどう判断したかを聞ける場に価値があります。

その場が成立したのは、登壇者の皆様が自社の判断を——うまくいった話も、迷った話も——公開の場で話してくださったからです。準備には相当な時間をかけていただいたはずで、それを引き受けていただいたことに、実行委員会一同、心より感謝しております。

またご一緒できることを楽しみにしております。
